# 🚀 Project Based Learning

This repository contains my journey of learning software development through building projects instead of relying only on tutorials.

## Why This Repository?

I realized that simply watching tutorials and reading documentation was not helping me develop real problem-solving skills. So I decided to learn by building.

The goal of this repository is to:

* Learn by creating real projects
* Improve problem-solving and debugging skills
* Build a strong portfolio
* Track my progress publicly
* Develop consistency and discipline

## Projects

### 1. Rock Paper Scissors 🎮

A browser-based Rock Paper Scissors game built using HTML, CSS, and JavaScript.

#### Features

* Play button to start rounds
* Random computer choice generation
* Winner determination logic
* Live score tracking
* Result display
* Player and computer choice display

#### Concepts Learned

* DOM Manipulation
* Event Listeners
* Functions
* Conditional Logic
* Variables and State Management
* Dynamic UI Updates

---

## Learning Philosophy

Instead of following endless tutorials, I follow this process:

1. Pick a project
2. Build it from scratch
3. Get stuck
4. Research solutions
5. Implement and improve
6. Repeat

The objective is not to memorize syntax but to learn how to think like a developer.
